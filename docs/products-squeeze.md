# Our Products squeeze carousel

The supplied `carousel-squeeze.tsx` reference is adapted to the established React JSX/Vite project in `src/components/ui/SqueezeCarousel.jsx`. `ProductsSection.jsx` provides the original eight products, descriptions, destination routes and generated image paths. `HomePage.jsx` now renders this section instead of the former three-product showcase and extra card row. `src/products-carousel.css` owns panel proportions, caption overlays, responsive layout and reduced-motion styles. Existing local fonts and blue brand colors are retained; no new dependency or TypeScript/shadcn migration was required.

Features: selected product expands while nearby panels and tail slats squeeze; one-second width transitions; subtle pointer expansion; matching product copy and detail link; previous/next wrapping, eight pagination controls, roving tab focus, ArrowLeft/ArrowRight/Home/End, and horizontal mobile swipe. On mobile the selected panel and one adjacent preview remain visible, with all eight products available through controls. No autoplay is enabled. The restored homepage anchor is `#products`.

Eight blue/white conceptual product images were generated with the built-in image_gen tool. They illustrate the products' domains rather than claiming to be actual application screenshots. Serving assets are `public/assets/generated/products/{payroll,billing,commerce,erp,fund,hotel,inventory,field}.webp`, approximately 40–80KB each. Original generated PNGs are copied into `artifacts/generated-products/`; default generator originals are retained. Source/output mapping is in `generated-product-images.json`, and the exact prompt recipe is in `product-image-prompts.md`.

`ProductShowcase.jsx` is retained as an unused legacy component. The homepage no longer renders its three featured tabs; navigation and product-detail pages still use the original catalogue and image data.

Validation: the full 20-test browser suite passed before the final mobile focus adjustment. Final carousel and accessibility checks passed after that adjustment, covering all eight destination links, wrapping controls, mobile Home/End focus and swipe. A mobile test locator was corrected to retain product indexes when inactive previews are hidden. Build/lint/format checks passed; desktop/mobile screenshots were reviewed. Previews: `artifacts/products-squeeze-desktop.png` and `artifacts/products-squeeze-mobile.png`.
